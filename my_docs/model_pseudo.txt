INPUT: LiDAR points [N, 5], 3 camera images [3, 960, 544]

1. FEATURE EXTRACTION
   LiDAR (10 sweeps merged) → Voxelize → PillarFeatureNet → PointPillarsScatter
   → SECOND backbone → SECONDFPN → bev_feat [1, 384, 128, 128]  (full 360° BEV)
   
   Images → ResNet50 → FPN → img_feats [4 levels]
     level 0: [1, 3, 256, 120, 68]  ← finest, stride 8
     level 1: [1, 3, 256,  60, 34]
     level 2: [1, 3, 256,  30, 17]
     level 3: [1, 3, 256,  15,  9]  ← coarsest, stride 64

2. HEATMAP GENERATION
   bev_feat → heatmap_head (2× conv) → heatmap [1, 7, 128, 128]

3. QUERY INITIALIZATION (fill empty tracking slots)
   heatmap.sigmoid() → scores [1, 7, 128, 128]
   
   MASK 1 — camera visibility:
     _build_camera_visibility_mask():
       project each BEV cell (x,y,z=0) through lidar2img into each camera
       valid = depth>0 & u∈[0,W] & v∈[0,H]
       any(cameras) → vis_mask [128, 128]  True=front half, False=rear
     scores *= vis_mask  ← rear half zeroed, no queries born there
   
   active track suppression → zero cells near existing tracks
   3×3 local max NMS (skip for bicycle, pedestrian)
   topk → N peaks (N = num empty slots)
   
   for each peak:
     bev_feat at (row,col) → lidar_bev_proj [256] → content vector
     peak class → category_embed [256] → add to content
     peak (x,y) → reference_point [3] in inv-sigmoid space
   → queries [300, 512], reference_points [300, 3]

4. ADD POSITIONAL ENCODINGS TO IMAGE FEATURES
   for each FPN level i:
     img_feats[i] += SinePositionalEncoding(H,W) + level_embeds[i] + cam_embeds
   (in-place addition, features now carry spatial + level + camera identity)

5. GT HEATMAP SUPERVISION (training only, runs in parallel with decoder)
   for each GT box:
     x,y → BEV grid cell (col, row)
     w,l → decode from log-space → grid cells
     radius = ceil(sqrt(w_cells²+l_cells²) / 2)  ← box-size-aware
     sigma = (2*radius+1) / 6.0
     place Gaussian blob on gt_heatmap[class, row, col]
   
   MASK 2 — same camera visibility:
     gt_heatmap *= vis_mask  ← only supervise front-half BEV
   
   focal_loss(heatmap.sigmoid(), gt_heatmap) → heatmap_loss

6. LAYER 0 — LiDAR BEV decoder
   self-attn:
     Q=K=V = queries+query_pos [300, 1, 256]
     → queries attend to each other [300, 1, 256]
     → LayerNorm + residual

   LiDARBEVCrossAtten:
     bev_feat [1, 384, 128, 128]
     → bev_proj Linear(384→256)
     → flatten → [16384, 1, 256]
     + 2D sine pos encoding [16384, 1, 256]
     Q=queries [300,1,256], K=V=bev_kv [16384,1,256]
     → nn.MultiheadAttention → [300, 1, 256]
     → output_proj + dropout + residual
     NO masking — full 360° BEV attended

   FFN: Linear(256→512)→ReLU→Dropout→Linear(512→256) + residual + LayerNorm

   reg_branch[0](q) → Δ(x,y,w,l,z,h) [300, 6]
   new_ref = sigmoid(Δxy + inv_sigmoid(ref_pts))  → detach
   ref_size += Δwlh                               → detach (detach_size=True)

   → intermediate[0] saved for loss

7. LAYER 1 — SMCA camera decoder
   q_layer0 = q.clone()  ← snapshot before layer 1 (for invisible query fallback)

   self-attn:
     queries attend to each other (same as layer 0)
     → LayerNorm + residual

   SMCACrossAtten:
     _fuse_fpn_levels(img_feats):
       levels 1,2,3 → bilinear upsample to level-0 size (120×68)
       concat → [1, 3, 1024, 120, 68]
       fusion_proj Linear(1024→256) → [1, 3, 256, 120, 68]

     _project_to_cameras(reference_points):
       denorm ref_pts using pc_range → metric (x,y,z)
       lidar2img @ [x,y,z,1] → pixel (u,v) per camera
       cx=u/img_w, cy=v/img_h ∈ [0,1]
       valid = depth>0 & cx∈[0,1] & cy∈[0,1]  [1, 300, 3]

     _compute_sigma():
       project 5 points (center + 4 axis-aligned half-extents) into each camera
       u_range, v_range = spread of projected box in feature-map pixels
       radius = ceil(norm(u_range, v_range) / 2)
       sigma = (2*radius+1) / 6.0  ← image-scale-aware, matches TransFusion

     _gaussian_mask(cx, cy, sigma):
       pixel grid [120×68] per camera
       gauss = exp(-0.5 * ((px-cx*W)² + (py-cy*H)²) / sigma²)
       → [1, 300, 3, 8160]

     MASK 3 — per camera validity:
       for each camera:
         attn = Q @ K^T * scale + log(gauss)  [1, 300, 8160]
         softmax → attend to camera pixels
         out = attn @ V  [1, 300, 256]
         accum += out * cam_valid  ← zero if query doesn't project into this cam
         count += cam_valid

     accum /= count.clamp(min=1)  ← average over valid cameras
                                     if count==0: accum=0
     no_cam_mask = (count==0)  [1, 300]  ← True = invisible to all cameras

     output_proj + dropout + residual + pos_encoding(ref_3d)

   INVISIBLE QUERY FALLBACK:
     q = torch.where(no_cam_mask, q_layer0, q)
     ← invisible queries revert to pure layer-0 state
     ← visible queries keep camera-refined state

   FFN + LayerNorm

   reg_branch[1](q) → Δ(x,y,w,l,z,h)
   new_ref = sigmoid(Δxy + inv_sigmoid(ref_pts)) → detach
   ref_size += Δwlh                              → detach

   → intermediate[1] saved for loss

8. DECODE BOXES (done for both layers)
   for layer in [0, 1]:
     cls_branch[layer]       → class logits      [300, 7]
     reg_branch[layer]       → xywlzh            [300, 6]  + ref_point offset
     direction_branch[layer] → sin/cos yaw       [300, 2]
     velo_branch[layer]      → vx, vy            [300, 2]
     → bbox [300, 10]

9. LOSS (training only)
   Hungarian matching on BOTH layer outputs independently
   loss per layer = focal_loss(cls) + L1(bbox) + heatmap_loss
   total_loss = loss_layer0 + loss_layer1 + heatmap_loss

10. TRACKING UPDATE
    layer 1 query features [300, 256] → QIM → propagate to next frame
    ref_points + predicted velocity → next frame initialization
    track scores → birth/death decisions

OUTPUT: boxes [300, 10], class scores [300, 7], updated track states
